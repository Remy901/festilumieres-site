# Site de FestiLumieres

Pages publiques de l'appli, pour la fiche App Store (iPhone et Mac).

| Page | Fichier | À utiliser pour |
|---|---|---|
| Accueil | `index.html` | URL marketing (facultatif) |
| Assistance | `assistance.html` | URL d'assistance (obligatoire) |
| Confidentialité | `confidentialite.html` | URL de politique de confidentialité (obligatoire) |

Version anglaise dans `en/` (`index.html`, `support.html`, `privacy.html`).

Site statique, sans script ni dépendance : GitHub Pages le sert tel quel
(`.nojekyll` désactive le traitement Jekyll). Couleurs néon cyan et magenta sur fond de nuit,
comme l'application.

## Adresses

- https://remy901.github.io/festilumieres-site/
- https://remy901.github.io/festilumieres-site/assistance.html
- https://remy901.github.io/festilumieres-site/confidentialite.html

Chaque `git push` sur `main` met le site à jour automatiquement (GitHub Pages, branche `main`, dossier racine).
L'application ouvre `assistance.html` depuis Réglages > « Assistance et contact ».
